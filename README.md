# 🎨 Logo Design Critic Chatbot

A smart, AI-powered assistant designed to provide expert constructive feedback and professional critique on logo designs. This project uses **Python**, **Streamlit** for the interactive user interface, and the **Google Gemini 1.5 Flash** model to analyze visual design elements.

---

## 🚀 Features
* **Image Upload:** Upload logo files in PNG, JPG, or JPEG formats.
* **Instant AI Analysis:** Leverages advanced computer vision to review design aspects.
* **Professional Feedback:** Provides insights into:
  * Color palette & visual psychology
  * Typography & font choices
  * Symbolism & brand relevance
  * Scalability, simplicity, & versatility
* **Actionable Advice:** Offers clear, professional recommendations for improvement.

---

## 🛠️ Tech Stack & Prerequisites
* **Language:** Python 3.8+
* **Framework:** Streamlit
* **AI Engine:** Google Generative AI (Gemini API)
* **Image Processing:** Pillow (PIL)
